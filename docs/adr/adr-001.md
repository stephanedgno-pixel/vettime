# ADR-001 : Framework web — FastAPI + Jinja2 + HTMX

- Statut : Accepté
- Date : 2026-11-03

## Contexte
VetTime est une application web transactionnelle (gestion des présences /
pointages pour cliniques vétérinaires), développée en solo dans le cadre du
cours INF1410. Exigences du cours : authentification, base SQL, déploiement
public (ThinkCentre + Cloudflare Tunnel). L'UI est majoritairement des
formulaires CRUD (pointages, congés, rapports). Le langage est libre ; on a
choisi Python.

## Décision
Backend API avec **FastAPI**, rendu HTML côté serveur via **Jinja2**, et
**HTMX** pour une UX progressive (mises à jour partielles sans framework
JavaScript SPA). Pas de build JS séparé.

## Alternatives considérées
- **React / Vue (SPA)** : build complexe, surkill pour des formulaires CRUD,
  déploiement plus lourd, courbe d'apprentissage raide. Rejeté.
- **Django** : batteries incluses mais moins d'API moderne intégrée et plus
  « magique » (moins explicite pour un étudiant qui doit défendre ses choix).
  Rejeté.
- **Flask seul** : pas de structure imposée → on réinvente routing/validation.
  Rejeté.

## Conséquences
- Déploiement simple (FastAPI sert le HTML) ; pas de pipeline de build JS.
- UX progressive via HTMX, adaptée au besoin.
- Validation Pydantic + OpenAPI auto = documentation API gratuite.
- Moins « sexy » qu'une SPA, mais adapté et courbe d'apprentissage gérable.
